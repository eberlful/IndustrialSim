# Separate critical logs from sampled telemetry

Decision requests, actions, rewards, failures, and Production Unit lifecycle transitions are written to a lossless ordered JSONL audit log. Optional state and performance telemetry is sampled and follows a configurable backpressure policy that may thin observations; closed, rotating Parquet fragments are derived for analysis and training rather than serving as the sole live record. Each run writes atomically to its own non-overwriting directory containing a manifest, resolved configuration, audit log, checkpoints, metric fragments, and summary; incomplete runs remain marked as incomplete. A run manifest records all relevant runtime, schema, model, configuration, and plugin versions. This prevents monitoring load or an incomplete Parquet footer from silently corrupting training evidence without forcing every high-volume metric to block the simulation.
