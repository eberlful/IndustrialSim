# Make reproducibility a core invariant

Given the same configuration, initial state, random seed, and action sequence, a run must produce the same result, including counterfactual continuations. Simulation time is represented as integer nanoseconds, and events are ordered by simulation time, explicit priority, and a monotonic sequence number. All randomness comes from named checkpointable Philox streams; draws are semantically addressed by stream, entity, and occurrence so that counterfactual branches experience common external randomness unless an action deliberately changes the relevant probability. Floating-point time, unordered iteration, and ambient randomness are forbidden in deterministic paths; this makes tests and direct comparisons between decision policies trustworthy.
